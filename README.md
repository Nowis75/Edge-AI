# AI na hraně

Zdrojové kódy tvoří podporu knihy - AI na hraně - Umělá inteligence na mikrokontrolérech, která je určena především inženýrům a vývojářům embedded systémů, kteří chtějí propojit svět mikrokontrolerů a IoT s moderním strojovým učením. Postupuje od obecných principů neuronových sítí a strojového učení, a postupně se zaměřuje na specifika Edge AI a jejich implementaci do reálných zařízení.
